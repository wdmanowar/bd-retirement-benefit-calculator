# bd-retirement-benefit-calculator
বাংলাদেশের সরকারি চাকরিজীবীদের অবসর সুবিধার আনুমানিক ক্যালকুলেটর। তারিখ থেকে কর্মকাল ও অর্জিত ছুটির জের, ছুটি নগদায়ন (লাম্পগ্র্যান্ট), আনুতোষিক (গ্র্যাচুইটি) ও মাসিক পেনশন হিসাব করে। হারের তালিকা পরিবর্তনযোগ্য। বাংলা ইন্টারফেস, মোবাইল-বান্ধব, ডার্ক থিম। সার্ভার ছাড়াই ব্রাউজারে চলে। HTML, CSS ও JavaScript দিয়ে তৈরি।
